# Agregar Accion 'Cargar' a Otaku

## Objetivo

Al igual que los 'tags' de VNDB los Animes, Personas, Mangas, y Personajes, de MAL sern cargados por un Dump en json

## Alcance

creacion el formulario base, BaseloadFileForm.
crear los herederos del formalario base como VNDBTagsDumpForm.


## Requisitos

- El formulario base, debe recibir el formato de archivos permitidos de los hijos.
- El Formulario hijo de Animes, Personas, Personajes, Mangas. debe poseer un CheckBox para indicar si se descargaran o no las imagenes.
- la data de Los formularios Animes, Personas, Personajes, Mangas debe almacenarce en las tablas Data corerspondiente.
- El formulario de de carga de Anime recbira el json de Animes con las imagenes extra de el mismo es decir va contra DataMalAnime, DataMalAnimePicture
- El formulario de de carga de Manga recbira el json de Mangas con las imagenes extra de el mismo es decir va contra DataMalMangas, DataMalMangasPicture
- Personas y personajes tienen el mismo comportamiento
- Los Dump solo cargaran datos a los Modelos Datos, la carga debe ser ordenada

## Antes de modificar

1. Revisar `VNDBTagsLoadView`.
2. Revisar el template asociado.
3. Revisar la configuración actual de Formularios.
4. Seguir el patrón existente.
5. Mantener nombres Ordenados
6. Crear las Vistas Summary correspondientes

## Criterios de aceptación

- Nombres de vistas acorde a los actuales Ej: AnimeMyAnimeListLoadView, AnimeLoadSummaryView.
- No se modifican funcionalidades fuera del alcance.
