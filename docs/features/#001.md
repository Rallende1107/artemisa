# Agregar columna Artista a DataDeezerAlbumListView

## Objetivo

Agregar una nueva columna `Artista` al listado de Albumnes.

## Alcance

Modificar únicamente lo necesario para que la columna aparezca
correctamente en el ListView/DataTable de Lista de datos · Álbum (Deezer).

## Requisitos

- Añadir el Campo Artista, al lado derecho del nombre del Album.
- Se podra buscar en los albumnes por el nombre del artista.

## Antes de modificar

1. Revisar `DataDeezerAlbumListView`.
2. Revisar el template asociado.
3. Revisar la configuración actual de DataTables.
4. Seguir el patrón existente.

## Criterios de aceptación

- La columna aparece en el listado.
- El valor mostrado es correcto.
- La columna permite ordenar si el resto de columnas lo permite.
- No se rompe el filtrado existente.
- No se modifican funcionalidades fuera del alcance.
