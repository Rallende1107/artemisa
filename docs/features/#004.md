# Renombre Modelos y Estandarizacion

## Objetivo

Logar Estandarizar los Modelos de Datos externos proveniendes de Dezzer VNDB My AnimeList o AnimeList

## Alcance

- Molelos, Formularios, Vistas, Formularios Dumps

    - Los modelos de Data pasaran a Renombrarse Como La Estrcutura [Prefijo][Sitio][Entidad]
    El prefijo sera Data indicnado que son Datos de un sitio exteno el segundo campo es El Sitio    VNDB / Dezeer / MyAnimeList y segido de que es el dats
    * Ejemplo
    * Modelos
        - DataF95GameVNDB -> DataVndbGame
        - DataCreatorVNDB -> DataVndbCreator
        - DataReleaseVNDB -> DataVndbRelease
        - DataMalCharacterVNDB -> DataVndbCharacter

- Formularios
    - Existiran los Fomrularios Basicos del CRUD
        - Create
            - DataVndbGameCreateView
            - DataVndbCreatorCreateView
            - DataVndbReleaseCreateView
            - DataVndbCharacterCreateView
        - Update
            - DataVndbGameUpdateView
            - DataVndbCreatorUpdateView
            - DataVndbReleaseUpdateView
            - DataVndbCharacterUpdateView
        - List
            - DataVndbGameListView
            - DataVndbCreatorListView
            - DataVndbReleaseListView
            - DataVndbCharacterListView
        - Delete
            - DataVndbGameDeleteView
            - DataVndbCreatorDeleteView
            - DataVndbReleaseDeleteView
            - DataVndbCharacterDeleteView
        - Data
            - DataVndbGameDataView
            - DataVndbCreatorDataView
            - DataVndbReleaseDataView
            - DataVndbCharacterDataView
        - Detail
            - DataVndbGameDetailView
            - DataVndbCreatorDetailView
            - DataVndbReleaseDetailView
            - DataVndbCharacterDetailView

## Requisitos
- Las Vistas ListDeben ser Alimentadas por las DataView.
- Se mantiene la Estrcutra la las ListView de Datos Actual, se Conserva la DetailView
- Nacera El Fomrulaio Dump de cada entidad.
- Nacera la Vista Download o export el cual generara el El dump para la carfa de la entidad

## Antes de modificar

1. Revisar Lo Modelos Afectados.
2. Revisar el template asociado.
3. Revisar las Vistas Afectadas.
4. Revisar las Vistas Nuevas.
5. Mantener Nombres Ordenados.
6. Iniar por Partes, Iniiando por Games, Music y Terminando con Otaku.


## Criterios de aceptación

- Nombres de vistas acorde a los actuales, Crear las Vistas Summary, y Export.
- No se modifican funcionalidades fuera del alcance.
