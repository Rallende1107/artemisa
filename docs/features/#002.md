# Agregar Accion 'Procesar' a selects de acciones en ListViews

## Objetivo

Agregar una nueva accion de `Procesar` al listado de Acciones.

## Alcance

Modificar únicamente lo necesario para que la acción aparezca
correctamente en el ListView/DataTable de Lista de datos.

## Requisitos

- Añadir la accion de 'procesar', al lsitado de acciones en las listas Data.
- Se podra procesar una data ya procesar las veces que se quiera, el boton esta despues de editar.

## Antes de modificar

1. Revisar `DataXXXXListView`.
2. Revisar el template asociado.
3. Revisar la configuración actual de DataTables.
4. Seguir el patrón existente.

## Criterios de aceptación

- La accion aparece en el listado.
- El valor mostrado es correcto.
- No se modifican funcionalidades fuera del alcance.
